## 〇、 使用说明

### 0.1 编号、规模与角色

| 字段 | 说明 |
| :--- | :--- |
| **编号** | `模块-序号`，如 `AI-07`。认领、提交、Bug 单都写编号。 |
| **规模** | **S** ≤ 1 人天；**M** 2~3 人天；**L** 4~5 人天。超过 L 的任务必须继续拆。 |
| **角色** | 程 = 程序；策 = 策划（数值 / 关卡 / 文案）；美 = 美术；音 = 音频；测 = 测试。 |
| **里程碑** | **M1** 核心白盒（单人可玩一局）；**M2** 完整校园；**M3** 打磨与局外。 |
| **依赖** | 必须先完成的任务编号。没有依赖的任务可以立刻开工。 |

### 0.2 协作约定

* 业务代码放 `game/`，界面放 `ui/panels/<模块>/`，配置数据放 `data/`，美术资源放 `assets/`（地址规则见 [02_美术资源清单](./02_美术资源清单.md) 第一节）。
* 跨系统通信只走 `Events` 上的信号，新增信号时在 `core/event/event_bus.gd` 写清参数含义。
* 每个任务交付时附带测试（`tests/**/test_*.gd`），并保证 `tools/test.sh` 全部通过。
* 数值一律进 `.tres` 配置（见 FW-11），代码里不写死数值。

### 0.3 框架现状（已完成，可直接使用）

| 模块 | 内容 | 位置 |
| :--- | :--- | :--- |
| 服务启动 | `App`：服务依赖声明、拓扑排序、按序初始化、循环依赖检测 | `core/app/` |
| 日志与参数 | `Log` 分级日志；`DebugArgs` 命令行参数 | `core/app/` |
| 事件总线 | `Events` 强类型信号 | `core/event/` |
| 资源 | `Assets`：地址寻址、同步 / 异步加载、加载组 + 进度、持有 / 释放、可替换 Provider；清单生成与校验工具 | `core/asset/`、`tools/` |
| 对象池 | `Pool`：分类、预热、取还、`_on_spawn` / `_on_recycle`、`AutoRecycle` | `core/asset/` |
| UI | `UI`：六层 CanvasLayer、NORMAL 返回栈、POPUP 遮罩、面板生命周期、`%` 绑定校验、显示动画、按钮按压回弹；通用面板 Toast / Confirm / Loading；主题 | `core/ui/`、`ui/` |
| 测试 | headless 测试运行器、`tools/test.sh`（含资源校验） | `core/testing/`、`tools/` |
